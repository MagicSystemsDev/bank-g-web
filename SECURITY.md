# Seguridad del sitio público

Todo archivo de este repositorio debe considerarse público. No incorporar secretos, credenciales, datos financieros o personales, respaldos, paquetes de instalación, licencias emitidas, evidencia cruda de Gate E, rutas internas ni detalles que permitan evadir controles.

Las capturas futuras deben utilizar datos ficticios y eliminar metadatos antes de publicarse. La web no requiere cookies, analítica, formularios ni servicios de runtime.
