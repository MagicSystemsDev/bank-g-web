# Bank G Web

Sitio público y case study de Bank G Offline 0.2.0. Es independiente del runtime y de los repositorios privados del producto.

## Desarrollo

```powershell
npm ci
npm run dev
npm run build
```

La exportación estática se genera en `out/`. `PAGES_BASE_PATH` permite publicar como project site de GitHub Pages. La variable opcional `NEXT_PUBLIC_PORTFOLIO_URL` configura el enlace de regreso al portafolio; su valor predeterminado es `https://pguale.github.io/about-me/`.

## Límites

Este repositorio no contiene instaladores, imágenes Docker, licencias emitidas, respaldos, datos reales, credenciales ni evidencia interna de certificación.
